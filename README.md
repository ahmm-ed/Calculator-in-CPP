C++ Switch Calculator

Purpose

The purpose of this project is to provide a practical, interactive console-based calculator built in C++ using a switch statement. It is designed to handle multiple continuous calculations, protect against division and modulus-by-zero errors, and format outputs cleanly to two decimal places.

How to Run the Program

Ensure you have a C++ compiler installed (such as g++).

Save your source code in a file named calculator.cpp.

Open your terminal or command prompt, navigate to the folder containing the file, and run the following commands:

g++ calculator.cpp -o calculator
./calculator


Example Input/Output

Input:

Enter your choice (1-6): 1
Enter first number: 15.5
Enter second number: 4.2


Output:

Result: 15.50 + 4.20 = 19.70
